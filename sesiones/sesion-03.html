01 · Importancia para la profesión jurídica

Volver a temas ↑

Sentencias, contratos, dictámenes y expedientes suelen circular en PDF. Para analizarlos en conjunto, primero necesitamos convertir su contenido en texto que un programa pueda buscar, comparar y organizar.

  • Búsqueda documental: localizar menciones de una norma, persona o institución en muchos archivos.
  • Comparación: detectar cambios entre versiones de un contrato o identificar cláusulas recurrentes.
  • Bases de datos: reunir número, fecha, materia y organismo de documentos para su análisis.
  • Análisis posterior: preparar textos para clasificación, estadísticas o consultas con modelos de IA.
PDF→Texto por página→Campos verificados→Tabla y análisis

Ejemplo de trabajo: construir una tabla de dictámenes con número, fecha y materia. Extraer el texto permite empezar; identificar esos campos y verificar su exactitud constituye una tarea adicional.

Guardar el archivo de origen y la página de cada resultado permite contrastar los datos con el documento original y explicar cómo se obtuvieron.

02 · Distinguir PDFs según su origen

Volver a temas ↑

La extensión .pdf describe el formato, pero no garantiza que contenga texto extraíble. Dos páginas visualmente similares pueden necesitar tratamientos distintos.

Origen del documento y estrategia de extracción
TipoQué contieneCómo extraerlo
Digital de origenExportado desde Word u otro programa. Habitualmente almacena caracteres y su posición.Leer la capa de texto con una librería de PDF.
Escaneado sin OCRImágenes de páginas en papel; vemos letras, pero el archivo no las almacena como caracteres.Reconocer el texto de las imágenes mediante OCR.
Escaneado con OCRImagen del documento más una capa de texto reconocida previamente.Extraer esa capa y comprobar su calidad; repetir OCR si resulta inutilizable.
MixtoCombina páginas digitales, escaneadas o imágenes con texto dentro de una misma página.Elegir el tratamiento por página o región, evitando duplicar texto.

Diagnóstico antes de programar

  1. Intenta seleccionar una frase y copiarla en un editor de texto.
  2. Comprueba si conserva caracteres, tildes y orden de lectura.
  3. Repite en varias páginas, incluyendo anexos: un PDF puede ser mixto.
  4. Si la extracción devuelve texto vacío o ilegible, inspecciona la página y determina si requiere OCR.

Que el texto sea seleccionable no demuestra que el PDF sea digital de origen: también puede tener OCR previo. «Digitalizado» suele referirse a un documento escaneado. Además, un PDF exportado puede contener letras convertidas en dibujos, sin texto utilizable.

Referencia: tipos de PDF y límites de la extracción en pypdf.

03 · PDFs digitales:

Volver a temas ↑

Cuando existe texto utilizable, podemos leerlo directamente sin reconocer cada letra desde una imagen. Esto suele requerir menos procesamiento que OCR y permite empezar con pocas líneas de Python.

Herramientas de extracción directa
HerramientaPara qué sirvePunto de atención
pypdfExtraer texto por página y manipular archivos PDF. Una entrada sencilla para la clase.No reconoce texto de imágenes.
PyMuPDFExtraer texto, bloques y coordenadas; convertir páginas en imágenes para un flujo de OCR.El orden de los bloques puede requerir ajustes.
pdfplumberInspeccionar posiciones y explorar tablas en documentos con texto.Las tablas necesitan ajustes según el diseño; una tabla escaneada requiere reconocimiento previo.

Instalar las librerías de extracción directa

Ejecuta estos comandos en la terminal, con el entorno virtual del proyecto activado. Puedes instalar solo la librería que vayas a utilizar.

python -m pip install pypdf
python -m pip install pymupdf
python -m pip install pdfplumber

Primer ejemplo: leer un artículo de la sesión 02

Desde la carpeta del proyecto, instala pypdf y guarda el siguiente código como extraer_texto.py. El ejemplo toma el primer PDF de articulos_pdf; puedes sustituir la ruta por otro documento.

python -m pip install pypdf
from pathlib import Path
from pypdf import PdfReader

archivos = sorted(Path("articulos_pdf").glob("*.pdf"))
if not archivos:
    raise SystemExit("Agrega un PDF a la carpeta articulos_pdf.")

archivo = archivos[0]
lector = PdfReader(archivo)
for numero, pagina in enumerate(lector.pages, start=1):
    texto = pagina.extract_text() or ""
    print(f"\n--- {archivo.name} · Página {numero} ---")
    print(texto if texto.strip() else "[Sin texto extraíble: revisar la página]")
python extraer_texto.py

Comprobación en clase: compara un párrafo con el PDF abierto. Revisa tildes, encabezados y columnas. Una salida vacía es una señal de diagnóstico, no prueba suficiente de que el documento sea escaneado.

La extracción directa es sencilla para texto corrido. Recuperar el orden de lectura, notas al pie o tablas puede ser más difícil: un PDF describe cómo presentar contenido en la página, sin garantizar su estructura lógica.

Documentación: pypdf · PyMuPDF · pdfplumber.

04 · PDFs escaneados: OCR y servicios de IA

Volver a temas ↑

El reconocimiento óptico de caracteres (OCR) transforma letras visibles en una imagen en texto procesable. En un escaneado sin capa de texto, primero hay que interpretar los píxeles; esto agrega preparación, procesamiento y posibles errores.

PDF a imágenes→Preparación→Reconocimiento→Texto y revisión

Para motores que reciben imágenes, renderizamos las páginas del PDF. Corregir la orientación, probar una resolución suficiente y mejorar el contraste puede ayudar. El desenfoque, las manchas, los sellos y la escritura manuscrita dificultan el reconocimiento.

Tres alternativas según herramientas y recursos

Comparación cualitativa de OCR local y servicios en la nube
AlternativaHerramientas y resultadoRecursos y dificultad
1 · OCR convencionalTesseract, desde Python mediante pytesseract. Punto de partida para transcribir páginas con texto impreso.Se ejecuta localmente en CPU. Hay que instalar el motor, el idioma español y preparar las imágenes; instalar pytesseract por sí solo no instala Tesseract. Sin tarifa de API, pero consume tiempo y recursos del equipo.
2 · OCR con modelos de MLEasyOCR y RapidOCR detectan regiones de texto y reconocen caracteres con modelos de aprendizaje automático.Requieren dependencias y modelos. EasyOCR usa PyTorch y admite CPU o GPU; RapidOCR ofrece motores como ONNX Runtime para ejecución en CPU. El consumo y la velocidad dependen del modelo, resolución y equipo.
3 · IA en la nubeAzure Document Intelligence ofrece extracción documental mediante modelos como Read y Layout. Gemini interpreta PDFs y puede transcribir o extraer campos mediante instrucciones.El proveedor realiza el procesamiento. Requiere conexión, cuenta y configuración de acceso. Hay cuotas, latencia y costos según uso; Azure suele contabilizar páginas y Gemini tokens, según servicio y modelo.
Clasificación didáctica: Tesseract moderno también utiliza redes neuronales. Estos grupos comparan formas de trabajo y despliegue; no son una escala garantizada de precisión. EasyOCR y RapidOCR no reconstruyen por sí solos toda la estructura de una tabla o un documento.

Instalar las librerías de OCR local

Elige la alternativa que quieras probar y ejecuta su comando en la terminal. Pillow permite abrir y preparar imágenes para pytesseract; PyMuPDF, instalado en la sección anterior, permite convertir las páginas del PDF en imágenes.

# Tesseract: interfaz de Python y manejo de imágenes
python -m pip install pytesseract pillow

# EasyOCR
python -m pip install easyocr

# RapidOCR con ONNX Runtime para CPU
python -m pip install rapidocr onnxruntime

Requisito adicional de Tesseract: instala también el motor siguiendo la guía de instalación para tu sistema operativo y agrega los datos del idioma español (spa.traineddata). El ejecutable debe estar en el PATH o indicarse en la configuración de pytesseract. Comprueba la instalación y que aparezca spa con:

tesseract --version
tesseract --list-langs

En Windows, EasyOCR recomienda instalar primero PyTorch y torchvision con el comando correspondiente a tu equipo (CPU o GPU), y luego instalar EasyOCR.

OCR local: elegir y configurar

  • Tesseract: comenzar con una página impresa clara y el idioma spa. La calidad de la imagen y la segmentación influyen en el resultado.
  • EasyOCR: cargar el lector una vez y reutilizarlo. Admite español; usar CPU permite trabajar sin GPU. Los modelos pueden descargarse en la primera ejecución.
  • RapidOCR: evaluar un motor de inferencia y un modelo adecuados. Comprobar compatibilidad con español y tildes; el modelo predeterminado no debe asumirse suficiente para cualquier idioma.

Los motores locales pueden ejecutarse sin enviar documentos a un proveedor una vez instaladas sus dependencias y modelos. Como orientación, EasyOCR puede requerir más memoria por su entorno PyTorch, mientras RapidOCR busca un despliegue eficiente; hay que medir ambos en el equipo y con documentos reales.

Referencias: Tesseract · EasyOCR: instalación, modelos y CPU/GPU · RapidOCR: modelos y motores de inferencia.

Instalar los clientes de los servicios en la nube

Para utilizar estos servicios desde Python, instala el cliente correspondiente. Además, necesitas una cuenta y las credenciales del servicio; instalar la librería no configura el acceso.

# Azure Document Intelligence
python -m pip install azure-ai-documentintelligence

# Gemini
python -m pip install google-genai

Guías de instalación: cliente de Azure Document Intelligence · cliente de Gemini.

Azure y Gemini: del texto a los campos

Azure Document Intelligence: usar Read para reconocimiento de texto o Layout para texto y estructura, como tablas. Es útil cuando necesitamos resultados organizados por elementos del documento.

Gemini: enviar un PDF y pedir una transcripción o campos específicos. La interpretación generativa puede omitir, alterar o inventar contenido; cada campo debe contrastarse con el original.

Ejemplo de instrucción para extraer campos:

Extrae de este oficio el número, la fecha y el organismo emisor.
Devuelve JSON con esos campos y la página de origen de cada uno.
Si un campo no aparece o no es legible, devuelve null.
Conserva la escritura original y no completes datos por inferencia.

Antes de elegir la nube, considera el volumen de páginas, el costo del servicio y si puedes enviar esos documentos al proveedor. Para ejercicios, utiliza archivos públicos o de práctica.

Documentación: Azure Document Intelligence · procesamiento de documentos con Gemini.

Cómo comparar consumo y calidad

Más resolución y más páginas incrementan el trabajo. En local, observa tiempo por página, memoria RAM y uso de CPU/GPU; en la nube, registra páginas o tokens facturados, tiempo de respuesta y reintentos. Estas medidas permiten comparar herramientas sin asumir un consumo fijo.

  1. Selecciona una misma página escaneada para todas las herramientas y transcribe manualmente un párrafo de referencia.
  2. Compara errores en palabras y en campos críticos: nombres, fechas, montos y números de documento.
  3. Registra configuración, resolución, tiempo y consumo. Distingue la descarga y carga inicial de modelos del procesamiento habitual.
  4. Elige según calidad suficiente para la tarea, recursos disponibles y volumen; conserva el original para revisar resultados.
Criterio de elección: extraer primero la capa de texto si es utilizable; probar OCR local para imágenes; evaluar servicios en la nube cuando sus capacidades documentales justifican el costo y el envío de archivos. Verificar siempre los datos críticos.
