Etapa 01

Instalación y preparación del entorno

Instalar Python

  • Descarga una versión estable desde python.org/downloads.
  • Windows: activa Add Python to PATH. macOS: completa el paquete oficial. Linux: comprueba primero python3 --version.
  • Verifica con python --version, py --version o python3 --version.

Instalar VS Code

  • Descarga desde code.visualstudio.com/download.
  • Instala las extensiones Python y Playwright, publicadas por Microsoft.
  • Todo no crearemos el entorno virtual: primero configuraremos la asistencia.

Crear y activar la sesión

Abre Copilot Chat y usa el siguiente prompt:

Configura esta carpeta como un proyecto Python para automatización web.
Antes de ejecutar comandos, explícame brevemente cada acción.
1. Comprueba qué comando de Python funciona en mi sistema.
2. Crea un entorno virtual llamado .venv.
3. Actualiza pip dentro de .venv.
4. Instala Playwright para Python dentro de .venv.
5. Instala solamente el navegador Chromium de Playwright.
6. Crea hola.py con una prueba mínima que abra example.com,
   imprima el título y cierre el navegador.
7. Indícame cómo seleccionar .venv como intérprete en VS Code.
No instales paquetes globalmente. Pide mi autorización antes de ejecutar.

Revisar y autorizar los comandos

Copilot puede proponer ediciones y ejecutar comandos en la terminal. Lee cada comando antes de aprobarlo. Debe usar el intérprete de .venv, no una instalación global. Si solo ofrece instrucciones, copia los comandos revisados en la terminal integrada.

Verificar el resultado

  • Confirma que existe la carpeta .venv.
  • Ejecuta Python: Select Interpreter y selecciona .venv.
  • Ejecuta hola.py y comprueba que Chromium abre example.com, imprime su título y se cierra.
  • Si algo falla, entrega el error completo a Copilot y pide primero un diagnóstico, no una reinstalación indiscriminada.
Idea pedagógica: GitHub y Copilot se configuran antes del ambiente del proyecto. Aún así, la primera automatización consiste precisamente en pedir a la IA que prepare un entorno reproducible, mientras el estudiante revise y comprenda cada comando.

Etapa 02

Automatización, web scraping y Playwright

Automatizar navegación

Reproducir acciones: abrir páginas, completar filtros, pulsar botones o descargar archivos.

Hacer web scraping

Localizar información publicada y convertir texto o atributos en registros estructurados.

Punto de encuentro: si una tabla aparece después de elegir un organismo y período, automatizamos la navegación y luego extraemos sus filas.

Decisión del curso

Usaremos Playwright

Esperas automatizadasReduce pausas arbitrarias.
Localizadores legiblesPermite buscar por rol, etiqueta o texto visible.
Evidencia integradaCapturas, trazas, descargas y DOM renderizado.
CodegenRegistra acciones y genera un borrador de código.
Contextos aisladosSepara sesiones de navegación eficiente.

Selección sugerida: Playwright tiene un ecosistema muy amplio. El objetivo no es "hacer scraping indiscriminado", sino construir una API coherente y reproducible a partir de reglas manuales.

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    page.goto("https://sitio-publico.example")
    print(page.title())
    browser.close()

Etapa 03

Trabajar con IA en asistencia de código

1. Recomendaciones generales sobre uso de IA en asistencia de código

La inteligencia artificial es una herramienta poderosa, pero requiere disciplina, claridad y responsabilidad. Estas recomendaciones te ayudarán a obtener mejores resultados y a evitar problemas comunes.

1.1 Instrucciones claras y específicas

  • Sé específico: en lugar de "haz un script que descargue datos", di "descarga los datos de la tabla con ID 'reporte-mensual' filtrando por mes y año, y guarda cada fila en un CSV".
  • Divide tareas complejas: si tienes una tarea grande, divídela en pasos lógicos. Pide primero la navegación, luego la extracción, luego la exportación.
  • Incluye contexto: explica qué tecnología usas, qué versiones, qué has intentado y qué errores obtuviste. Más contexto = mejores respuestas.
  • Define el resultado esperado: no solo digas qué quieres, sino cómo se vería el resultado. Por ejemplo: "la salida debe ser un archivo CSV con columnas: Nombre, Fecha, Monto, Estado".

1.2 Información sensible: qué NO compartir

  • Nunca compartas credenciales: usuarios, contraseñas, claves API, tokens de autenticación. Si necesitas acceso, pide a la IA que te ayude a gestionar variables de entorno (.env).
  • No incluyas datos personales: si trabajas con un CSV que contiene nombres, cédulas o emails reales, anonimiza los datos antes de compartir.
  • Evita URLs con parámetros sensibles: si una URL contiene sesión de usuario, ID privado o clave, reemplázala con un placeholder: "https://ejemplo.com/?sesion=[TU_SESION]".
  • Cuidado con el código de terceros: si usas código de un repositorio privado o de clientes, no lo compartas directamente. Describe el problema en términos generales.
  • Manejo de logs y errores: si un error contiene datos sensibles, elimínalos. Por ejemplo: en lugar de "Error: invalid user 'juan.perez@empresa.cl'", escribe "Error: invalid user".

1.3 Validación de respuestas de IA

  • No confíes ciegamente: la IA puede generar código que se ve correcto pero tiene errores lógicos o de seguridad.
  • Prueba en un ambiente aislado: antes de ejecutar código en producción, pruébalo en una rama local o un entorno sandbox.
  • Verifica dependencias: si la IA sugiere un paquete, comprueba que exista en PyPI, que esté mantenido y que sea compatible con tu versión de Python.
  • Lee el código completo: no copies fragmentos aislados. Entiende la lógica general: cómo se abre el navegador, cómo se espera a elementos, cómo se guardan datos.
  • Pide explicaciones: si no entiendes una línea, pregunta "¿qué hace esta línea y por qué es importante?".

1.4 Iteración efectiva con IA

  • Feedback específico: en lugar de "no funciona", di "el script se abre pero no encuentra el botón con texto 'Aplicar filtro'".
  • Mantén el contexto: guarda la conversación. Si necesitas cambios después, puedes referir a partes anteriores sin repetir todo.
  • Pregunta alternativas: si una solución no te convence, pide "¿hay otra forma de hacer esto?" o "¿cuáles son las ventajas y desventajas de esta opción?".
  • Solicita mejoras incrementales: primero un script básico que funcione, luego refactorización, luego optimizaciones.

1.5 Responsabilidad legal y ética

  • Respeta términos de servicio: si una web prohíbe scraping, no lo hagas. Busca una API o solicita acceso oficial.
  • No eludas controles de acceso: no uses IA para bypassear login, 2FA o captchas. Usa siempre credenciales propias o solicitadas.
  • Licencias de código: si copias código de una librería, respeta su licencia (GPL, MIT, Apache, etc.). La IA puede no mencionar esto.
  • Documentación y auditoría: registra qué datos extraes, de dónde, cuándo y por qué. Esto es importante para transparencia y cumplimiento.

2. Marco de trabajo con IA: archivo AGENTS.md

La IA funciona mejor cuando recibe una especificación estable y evidencia. No empleamos pidiendo "haz un scraper": registramos qué debe ocurrir, qué datos necesitamos y cómo validaremos el resultado.

3. Recomendaciones para trabajar con Playwright e IA

Playwright es potente pero requiere práctica. Cuando trabajes con IA, sigue estas recomendaciones para obtener código robusto y mantenible.

3.1 Localizadores: el corazón de una automatización

  • Prioridad de selectores (de más a menos robusta):
    • 1. Por rol y nombre: page.get_by_role("button", name="Filtrar")
    • 2. Por label: page.get_by_label("Mes")
    • 3. Por texto visible: page.get_by_text("Aplicar")
    • 4. Por atributos estables: page.get_by_test_id("submit-btn")
    • 5. CSS simple (último recurso): page.locator(".action-btn")
  • Pide a la IA que explique cada selector: "¿por qué elegiste este selector y no otro? ¿Qué pasaría si el HTML cambia?".
  • Evita selectores frágiles: si la IA genera page.locator("div:nth-child(3) > button"), pídele una alternativa más robusta.

3.2 Esperas y sincronización

  • Usa esperas explícitas: page.wait_for_load_state("networkidle") o page.locator("table").wait_for(timeout=10000).
  • Evita sleep: no uses time.sleep(2) a menos que sea por animaciones muy específicas. Documéntalo.
  • Captura tiempos de espera: si un elemento tarda mucho, es señal de que el selector es frágil o que el sitio cambió.

3.3 Manejo de errores

  • Pide try-catch estructurado: la IA a veces genera código sin manejo de excepciones. Solicita: "Agrégale try-catch con logging de errores".
  • Logging detallado: logging.info("Navegando a página 2...") ayuda a debugging. Pídele a la IA que agregue logs.
  • Recuperación elegante: "Si el elemento no existe, ¿qué debería hacer el script? ¿Reintentar? ¿Registrar y continuar?".

3.4 Validación de datos

  • Extrae luego valida: primero obtén los datos, luego valida que sean correctos (no vacíos, tipos esperados, etc.).
  • Pide pruebas de datos: "¿Qué pasa si la tabla está vacía? ¿Si tiene una fila? ¿Si tiene 1000?".
  • Comparación con la página: el script debe reportar: "Se encontraron 45 registros en la tabla y se extrajeron 45. OK."

3.5 Codegen como punto de partida

  • Codegen genera borrador, no código final: úsalo para grabar acciones, pero siempre refactoriza.
  • Limpieza de código: Codegen puede tener acciones redundantes. Pídele a la IA: "Limpia este código, elimina acciones innecesarias, extrae funciones reutilizables".
  • Comentarios y documentación: pide que agregue comentarios explicando qué hace cada sección.

3.6 Testing y reproducibilidad

  • Ejecuta en dos ambientes: en tu máquina y en otra (o CI/CD) para verificar que funciona siempre.
  • Diferentes navegadores: Playwright soporta Chromium, Firefox, WebKit. Prueba al menos en Chromium.
  • Versioning del sitio: si el sitio cambia, documéntalo: "Versión: 2024-09-01. Cambio: Se agregó filtro de rango de fechas".

3.7 Preguntas clave para hacer a la IA

  • "¿Qué pasa si este selector falla?"
  • "¿Cómo sabemos que la página cargó completamente?"
  • "¿Cuál es el máximo número de reintentos si falla?"
  • "¿Cómo diferenciamos entre 'error temporal' y 'error estructural'?"
  • "¿Qué datos deberíamos registrar para debugging?"
  • "¿Cómo escala esto si hay 10 mil registros en lugar de 45?"
Resumen: La IA es mejor cuando tienes especificaciones claras, evidencia visual, feedback iterativo y preguntas específicas. No es "haz todo automáticamente", sino "ayúdame a construir esto de forma robusta".

Etapa 04

Primera tarea: explorar el HTML de práctica

En esta primera tarea no navegaremos al Portal de Transparencia. Usaremos el Laboratorio de práctica para Codegen, una página ficticia que contiene botones, menús, formularios, tabla y controles de ratón.

1. Abrir Codegen

Desde la terminal, ejecuta python -m playwright codegen --output evidencia/codegen/flujo_inicial.py https://tu-url-del-laboratorio. Si trabajas con la versión local, usa una ruta file:// y guarda el archivo directamente con el mismo comando.

2. Recorrer la navegación

Haz clic en "Filtros y formulario", selecciona opciones y aplica filtros. Regresa y explora los botones de menú, la tabla, los botones de fila y la paginación.

3. Practicar interacciones de ratón

Pasa el puntero por la tarjeta de práctica, haz clic, prueba doble clic y clic derecho. Cambia el deslizador y observa los valores y el código que Codegen propone.

4. Guardar y revisar el código

Guarda el borrador con el comando python -m playwright codegen --output evidencia/codegen/flujo_inicial.py https://tu-url-del-laboratorio o con la ruta file:///ruta/al/laboratorio.html si usas el archivo local. Identifica los localizadores, elimina acciones innecesarias y explica qué fragmentos corresponden a los pasos manuales.

5. Repetir en modo Inspector

Usa Codegen para generar código y localizar selectores. No es una grabadora que siempre produzca código final: valida los selectores y los resultados en una ejecución limpia.

Meta de la tarea: producir un script que navegue por al menos tres secciones, aplique un filtro, abra un menú contextual, inspeccione una fila y ejecute una interacción con el ratón.
