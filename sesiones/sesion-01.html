Etapa 01 · Instalar y preparar el entorno

Antes de escribir código, configuramos Python, creamos un entorno virtual y aseguramos que el flujo sea limpio y reproducible.

Paso 1: Verificar Python

python --version
python3 --version

Así confirmamos la versión disponible antes de crear el entorno.

Paso 2: Crear un entorno virtual

python -m venv .venv

Paso 3: Activar el entorno

# macOS / Linux
source .venv/bin/activate

# Windows
.venv\Scripts\activate

Paso 4: Instalar Playwright

pip install playwright
python -m playwright install chromium

Paso 5: Crear script mínimo

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    page.goto("https://www.uai.cl/")
    print(f"Título: {page.title()}")
    browser.close()

Ejecuta:

python hola_mundo.py

Deberías ver que se abre un navegador, carga la página, imprime el título y se cierra.

Paso 6: Seleccionar intérprete en VS Code

En VS Code:

  • Abre la paleta con Ctrl+Shift+P o Cmd+Shift+P.
  • Selecciona Python: Select Interpreter.
  • Elige el entorno .venv creado en la carpeta del proyecto.
Nota: No instales paquetes globalmente ni ejecutes nada sin pedir autorización previa.

Etapa 02 · Automatización web con Playwright

Playwright permite controlar un navegador real, navegar, interactuar con controles, esperar estados y extraer datos de páginas web.

Conceptos fundamentales

  • Navegación: abrir una URL, esperar a que cargue, avanzar por la interfaz.
  • Interacciones: clicks, selección de opciones, autocompletar campos.
  • Validación: confirmar que una tabla o botón apareció antes de continuar.
  • Extracción: leer texto, atributos o filas de una tabla.

Ejemplo de flujo

from playwright.sync_api import sync_playwright

with sync_playwright() as p:
    browser = p.chromium.launch(headless=False)
    page = browser.new_page()
    page.goto("https://sitio-publico.example")

    page.wait_for_load_state("networkidle")
    page.get_by_role("button", name="Filtros").click()
    page.get_by_label("Organismo").select_option("salud")
    page.get_by_role("button", name="Aplicar").click()
    page.locator("table tbody").wait_for()

    rows = page.locator("table tbody tr").all()
    for row in rows:
        cells = row.locator("td").all()
        print([cell.text_content() for cell in cells])

    browser.close()

Herramientas integradas

  • Codegen: python -m playwright codegen https://tu-sitio. Graba lo que hagas y genera código.
  • Inspector: permite ver localizadores sugeridos en tiempo real.
  • Capturas: toma screenshots en cada paso útil para auditoría.

Etapa 03 · Trabajo con IA para automatización

1. Recomendaciones generales

La IA es útil para acelerar tareas, pero requiere disciplina, contexto claro y validación humana.

  • Define claramente el objetivo, el sitio web, los datos esperados y el formato final.
  • Indica el alcance y los límites del proyecto: ¿qué se extraerá y qué no?
  • Usa prompts muy específicos. Evita instrucciones ambiguas o demasiado generales.
  • Pide que te muestre el código y explica qué hace cada parte antes de ejecutarlo.

2. Plantilla sugerida

# Objetivo
Automatizar [sitio o sistema] para obtener [tipo de datos] del período [periodo].

### Alcance
- Página inicial: [URL]
- Resultado esperado: [columnas, formato, cantidad de filas]
- No iniciar sesión ni eludir controles de acceso.
- Datos a excluir: [información sensible, PII, etc.]

3. Buenas prácticas

  • Describe primero el flujo manual observado.
  • Comparte URLs, nombres de botones y mensajes de error si falla algo.
  • Haz que la IA documente los pasos y las validaciones.
  • Revisa siempre el código generado antes de ejecutarlo.

Etapa 04 · Práctica: explorar un laboratorio

En esta práctica se observa un sitio de ejemplo con filtros, tabla de resultados y controles de navegación. El objetivo es recorrer el flujo mínimo para extraer datos con autonomía y validación.

Flujo sugerido

  1. Abrir la página principal.
  2. Acceder al panel de filtros.
  3. Elegir una opción válida.
  4. Aplicar filtro y esperar la tabla.
  5. Extraer datos relevantes y revisarlos.
Meta: crear un script que navegue, aplique un filtro y registre el resultado en consola o en un archivo CSV.
