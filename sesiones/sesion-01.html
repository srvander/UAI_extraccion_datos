Etapa 01

Instalación y preparación del entorno

Antes de escribir código, configuraremos Python, crearemos un entorno aislado y instalaremos Playwright. No instales paquetes globalmente.

Paso 1: Verificar Python

Abre una terminal y ejecuta:

python --version

o

python3 --version

Asegúrate de tener Python 3.8+. Si necesitas instalar o actualizar Python, descárgalo desde python.org.

Paso 2: Crear un entorno virtual

En la carpeta del proyecto, crea un entorno aislado:

python -m venv .venv

Paso 3: Activar el entorno

En macOS / Linux:

source .venv/bin/activate

En Windows:

.venv\Scripts\activate
