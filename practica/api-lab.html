Sirve este proyecto desde su raíz con python -m http.server 8000 y abre http://localhost:8000/practica/api-lab.html. Los datos y documentos son ficticios.

Los datos aún no se han solicitado.

Observa: la respuesta de articulos.json contiene una lista de objetos y rutas de documentos. El filtro de este laboratorio se aplica en el navegador después de recibir el JSON; en otros sitios puede aplicarlo el servidor.

Prueba con HTTPX

from pathlib import Path
from urllib.parse import urljoin
import httpx

base = "https://srvander.github.io/UAI_extraccion_datos/practica/api/"
with httpx.Client(timeout=10) as client:
    respuesta = client.get(urljoin(base, "articulos.json"))
    respuesta.raise_for_status()
    articulos = respuesta.json()["resultados"]
    for articulo in articulos:
        print(articulo["titulo"], articulo["documento"])

    url_documento = urljoin(base, articulos[0]["documento"])
    documento = client.get(url_documento)
    documento.raise_for_status()
    Path("lectura-01.txt").write_bytes(documento.content)
